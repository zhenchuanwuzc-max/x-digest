产品是什么

官方自述beacon.sh 写把 Claude Code、Cursor、Codex、OpenCode 等 20 多种工具的会话变成可累积的知识，让下一个 Agent 不用从头学。

事实情报站周榜显示序 1，本周票 429。原链是 Product Hunt 的 asymptotelabs。该页本次不作为正文来源。仓库是 Asymptote-Labs/agent-beacon。

给谁

官方自述给同时用多款编程 Agent、希望纠正和调试路径能跨工具留下的人。README 写一个 Agent 解决过的问题不必让另一个从头再学。

工作流程与场景

官方自述首页把流程写成三步。先留下提示、工具调用、修改和结果。再从成功会话里抽出可复用技能。人看过之后，以后的 Agent 用 MCP 或 Agent Skills 取回。

事实2026-11-06 的 GitHub API 返回 MIT，公开星 3,314，fork 292，语言 Go。星不是安装数。

价格、开放与权限

官方自述定价页 的静态文本写开始是 0 美元。Beacon Cloud Pro 按年计费写着每月 20 美元，并写省 25%。团队档写着每席每月 30 美元，同样注明按年计费。页面上还有 Loading 字样，结账时数字可能不同。我们没有下单。

待核本地安装是否完全不要账号，以 README 的安装段为准。这次没有逐步点完安装器。

真实使用信号

事实周榜 429 票来自情报站，范围是 2026-11-02 到 2026-11-05 的最高日榜票，不是我们数出来的一周用户。API 星数是同日抽样。

国内替代

事实silo-memory 写记忆留在本机，用 SQLite 做检索，不把原文送到外部服务。它没有 Beacon 这种跨工具抽技能再放回 MCP 的描述。

事实claude-mem 的安装说明会引导浏览器登录，并有 30 天试用。Beacon 的差异写在跨工具会话和技能复用。我们没有并排安装。

可做的窄切口

建议只做中文项目的一份会话结束摘要，文件留在仓库里。下一次无论用 Cursor 还是 Claude Code，都先读这份文件。

最小版与不做的范围

建议一个仓库，五天，每天一份 markdown。内容只保留决定和踩坑，不上传。

不做不做托管技能市场，不宣称比 Beacon 更懂全部工具，不把 429 票写成用户数。

验证办法与建议的成功和停止条件

建议成功是换了一款编程工具之后，仍能靠那份 markdown 少解释一遍目录约定，并且文件里没有密钥。

建议停止条件是每天都要手改摘要，或者一次把令牌写进了文件。

流量和付费

事实页面写 0 美元可以开始。Pro 的 20 美元是年付价目上的静态文本。429 票不是席位。

建议可以做一条「两个工具共享一份项目记忆」的演示。收费要等有人连续五天留下文件。

风险

风险会话里有命令和密钥。云档把记录交给对方。定价页的 Loading 说明标价可能还没定死。和 claude-mem、Silo 挤在同一类需求里。
