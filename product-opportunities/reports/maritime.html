产品是什么

官方自述maritime.sh 把 Agent 电脑分成会睡眠的 agent box、跑完即删的 sandbox、可看屏幕的 Linux 或 Windows 桌面，以及 Android 手机。

事实情报站显示序 3，156 票，原链是 Product Hunt。该页 403。不要把 maritime.ai 当成这个产品，这次没有使用那个域名。

给谁

官方自述定价页用问题区分。要在对话之间留文件，用 agent box。任务结束就丢，用 sandbox。需要屏幕或 Windows，用按需电脑。对象是把环境交给 Agent 的开发者，不是自己远程办公的个人桌面用户。

工作流程与场景

官方自述sandbox 在任务结束时连磁盘一起删。agent box 空闲睡眠，大约一秒唤醒。桌面允许人接管。这些是定价页和首页的描述，我们没有创建过实例。

价格、开放与权限

官方自述定价页 2026-11-06 写 agent box 每 2 GB 每月 1 美元，含 5 GB 磁盘，超出每 GB 每月 0.08 美元。sandbox 每 vCPU 和 2 GB 每小时 0.011 美元，按秒、无最低时长。Linux 桌面醒着每小时 0.12 美元。Windows 桌面每小时 0.18 美元且含许可，Growth 及以上。Android 每小时 0.15 美元。

国内替代

事实扣子云电脑按 CU·天，文档给出 2C4G 为 2 CU、每天 12 积分每 CU。Maritime 的 sandbox 按秒，并且单列 Windows 许可。一个适合放进现有扣子订阅，一个适合按任务秒数结算。

事实UBox 和 Devicebase 解决的是手机或浏览器控制，不是 Maritime 定价页上的 Windows 桌面和大规模 sandbox。

可做的窄切口

建议不要重做云。只做一个很窄的封装。把「跑完这条生成脚本就销毁」写成对某一家已有云的一页说明。
