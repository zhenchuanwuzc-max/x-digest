产品是什么

官方自述README 写它由 Together AI 制作，是 Claude Code、Codex、Cursor、OpenCode 的设计技能。目录有 50 个主题。每个主题是材质，不是页面提纲。

事实2026-11-06 API 返回 MIT，公开星 48,903，fork 2,591。情报站快照是本周 +7,622、总星 48,695。

给谁

官方自述给要 Agent 出页面、又不想要模板腔的人。redesign 保留内容和接线，audit 只出报告。

工作流程与场景

官方自述预检读字体、色板和是否已有锁住的 design.md，并要求照片、截图和真实数字，声明不编造。theme.mjs 先给三个主题。英雄区单独做完并冷审，再做页面其余部分。sloplint --render 在八个宽度检查，然后换一个新上下文的评审收尾。

官方自述Floor 不过就不发布，例子包括对比度、焦点、减少动效、编造事实、手机布局坏掉。Reflex 是模型的默认习惯，有理由可以记录后推翻。Finish 不挡发布。

事实浏览器检查需要 puppeteer-core 和 Chrome。没有它们时 README 说静态检查仍能跑。我们两种都没跑。

价格、开放与权限

事实许可 MIT。README 写 custom on request，没有标出定制价格。这次打开的 usehallmark.com 也是安装命令和演示，没有价目表。

真实使用信号

事实榜单热度加上 API 星数。官网演示写 Without 26 issues、With Hallmark 0 issues，并注明数字来自它自己的 linter。那是官网自述，不是独立复测。

待核50 个主题是否都可用、定制是否收费，没有逐个打开主题文件。

国内替代

事实README 的参照列表里已经写了 huashu-design 和 impeccable。中文对比文见 aiku123。huashu 的差异是中文流程、PPTX 和 84 个风格。Hallmark 的差异是主题抽取加浏览器门禁。

假设把英文主题译成中文不会形成差别。差别只会出现在中文交易页特有的失败模式。

可做的窄切口

建议做「禁止编造销量和倒计时」这一类中文活动页规则。输出是失败清单，不是新的视觉主题。

最小版与不做的范围

建议五条规则，一张活动页，改前改后各一张图。规则文件放进 Cursor skill。

不做不克隆 50 个主题。不使用 README 点名的图库许可问题去再分发照片。照片库条款以仓库为准，我们没有逐张核对。

验证办法与建议的成功和停止条件

建议拿 6 个真实中文活动页跑规则。成功是每个页面至少一条规则被作者接受，且没有把真实价格判成假数据。

建议停止条件是规则只会报 Inter 字体和紫渐变，作者改完仍觉得没有用。

流量和付费

事实没有官价。播放可以来自对比图。

建议先发对比，不设付费。有人把规则要进自己的仓库，再谈按站定制。

风险

风险和 impeccable、huashu-design 挤在同一周的关注里。浏览器 lint 依赖本机 Chrome。主题文件若直接再分发，要单独看 MIT 以外的照片许可。
