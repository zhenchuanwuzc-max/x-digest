产品是什么

官方自述README 称它是编程 Agent 的设计词汇。用 polish、bolder 改已有界面，用 critique、audit 做评审，并用 62 条确定性规则抓模板化设计。这些规则不调用模型，也不要 API key。

事实GitHub API 在 2026-11-06 返回许可 Apache-2.0，语言栏为 Rust，主页指向 impeccable.style。情报站快照把它放在本周涨星第 1，本周 +10,921，总星 103,844。同日 API 的公开星是 104,087。两个数字都不是安装人数。

给谁

官方自述README 列出 Claude Code、Cursor、Codex、Copilot、Devin、Gemini CLI、OpenCode、DeepSeek Harness 等。对象是已经在用这些工具改界面的人。

官方自述README 写它最强的地方是改已经存在的界面。从零做新站也可以，但作者把那叫更难的模式。

工作流程与场景

官方自述在项目根执行 npx impeccable install，然后在 Agent 里跑 init。init 追问它推断不出的受众和约束，写出 PRODUCT.md。之后的命令读这个文件。document 会另写 DESIGN.md。

官方自述命令分成改调性、评审、收尾、浏览器里挑选变体、以及规划。live 模式在本地开发服务器上选中元素并换变体。README 写明 live 只改本地仓库，并警告不要为了它去放宽线上站点的 CSP。

事实检测可以在 Agent 钩子、命令行或 Chrome 扩展里跑。扫源码只有模式规则。对比度和过小字号要扫渲染后的 URL。我们没有跑其中任何一种。

价格、开放与权限

事实API 与 README 都是 Apache-2.0。README 没有 SaaS 价目。

官方自述新设计开始时会向 impeccable.style 拉一组视觉方向。关掉遥测后，项目名、文件和 PRODUCT.md 仍按 README 所说不会上传，但拉目录的请求还在。隐私页我们这次没有逐项复读，遥测字段以 隐私页 同站文档为准，细节待核。

官方自述live 的 Apply 在没有聊天会话轮询时，可能调用本机 codex 或 claude，并带上绕过审批的参数。这是 README 写明的权限行为。不熟悉的仓库里要先看它。

事实aiku123 的 2026-10-28 对比 把 hallmark、impeccable、ai-design-skills、huashu-design 放在一起。那篇文章自己的星数是 10 月 28 日口径，不能拿来当今天的星数。它能证明的是中文盘点已经存在。

假设空隙更像中文交易页的检测规则，而不是再翻译 24 个英文命令。这个判断还没被用户验证。

可做的窄切口

建议只做电商详情和活动页。规则写成中文例子。检测结果输出改哪一段，而不是再提供一套视觉主题。

最小版与不做的范围

建议十条约定加三张对比图，装成一个 Cursor skill。约定只覆盖渐变、假数字、英文占位和过小字号。

不做不宣称全面超过 impeccable。不把 Apache-2.0 仓库整份搬进闭源包。不在没跑过的情况下展示「62 条全通过」。

验证办法与建议的成功和停止条件

建议找 8 个正在用 Cursor 改中文活动页的人。成功是其中 5 人愿意把检测留在仓库里超过 7 天，并且能指出一条规则改了他们的页面。

建议停止条件是 7 天里没人留下 skill，或对比图播放高但没人要规则文件。流量不能代替留下。

流量和付费

事实官方没有标出的 SaaS 价格。仓库是开源技能。

假设收入更可能来自定制规则或录屏课，而不是星本身。这是猜测。

建议先用同一提示词的两张截图做一条短视频。付费实验要等有人留下 skill 再做。
