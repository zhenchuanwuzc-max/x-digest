产品是什么

官方自述README 说它捕获会话里的工具使用，生成摘要，再注入以后的会话。描述里点名 Claude Code、OpenClaw、Codex、Gemini、Hermes、Copilot、OpenCode。

事实2026-11-06 的 GitHub API 返回 Apache-2.0，公开星 113,635，fork 9,855，open issue 130。情报站快照是本周 +8,822、总星 113,500。两边都不是用户数。

给谁

官方自述给跨会话、跨工具继续同一个项目的人。README 也单列团队功能 TeamBrain，每个人选择分享什么。

事实中文模式写在 README 里。CLAUDE_MEM_MODE 设为 code--zh 时，观察和摘要用中文。这是配置说明，我们没有跑。

工作流程与场景

官方自述生命周期钩子覆盖 SessionStart、UserPromptSubmit、PreToolUse、PostToolUse、Stop、SessionEnd。本地 worker 提供 HTTP API 和查看页。存储是 SQLite。检索一层是 mem-search，另一层 README 写了 Chroma 向量库。

官方自述默认安装 npx claude-mem install 会在浏览器里用邮件链接登录，领取 memory key，并打开 30 天试用。README 写试用期内记忆不走你的 Anthropic 套餐。试用结束若未订阅，就退回你的套餐。加 --provider、或设置 CLAUDE_MEM_ONLINE_OPTIN=false，可以跳过登录。

官方自述截图默认关闭。只有同时打开 Cloud Sync 和图像推理才会上传或送给观察模型。排除敏感内容用标签，具体标签写法以文档为准，这里不复述。

官方自述2026-11-06 打开的 cmem.ai 写 30 天免费试用，之后 CMEM Pro 每月 30 美元。引擎页面同时写开源。我们没有下单，也没有看到税费和席位表。

国内替代

事实silo-memory 0.3.5 的摘要是给编程 Agent 的本地长期记忆，SQLite FTS5 加关键词图，技能覆盖 Claude Code、Codex、OpenCode、Cursor、Grok。正文写原文和索引都在本机，不发送到外部服务。仓库 flynn-eye/silo-memory 同日可打开。

假设和 claude-mem 的差别在托管观察者、跨工具云同步和团队共享。若只需要单机回忆，Silo 的描述已经覆盖「开始时召回、结束时沉淀」。我们没有并排安装。

可做的窄切口

建议只做中文项目的会话结束摘要，文件留在仓库里，不上传。不要做账号、向量库和团队空间。

最小版与不做的范围

建议一个 hook。会话结束写 markdown。下次把该文件放进上下文。只服务一个自己的仓库。

不做不做托管记忆、不做截图同步、不对比「省了多少 token」。官方写约 10 倍 token 节省，那是 README 的检索流程说明，不是我们测到的数。

验证办法与建议的成功和停止条件

建议连续 5 个工作日用同一仓库。成功是第 5 天不用重新解释目录约定，且摘要文件里没有出现密钥。

建议停止条件是摘要每天都要手改，或一次把令牌写进了文件。

流量和付费

事实开源引擎加上官网写出的 30 美元 Pro。星数不能换成订阅。

建议内容可以讲失忆。收费要等本地摘要真的被第二天用上，再决定要不要做同步。

风险

风险记忆里会有命令、路径和密钥。云同步把这个库交给第三方。官方记忆功能若变强，插件的理由会变薄。安装器默认要登录，和「纯本地」不是一回事。
