产品是什么

官方自述团队页 写把 Agent 的批准从手机完成，并留下团队记录。定价页 写一个人也可以用，手机 App 和 Mac App 包含在内。

事实情报站显示序 2，158 票。原链接是 Product Hunt。该页本次 403。

给谁

官方自述团队文档写给需要知道谁点了同意的人。提问可以到个人，也可以到你指定步骤的负责人。个人方案写给跑很多 Agent 的一个人。

工作流程与场景

官方自述团队文档 写价格，并说明团队记录可以导出 CSV 和 JSON，记录保留 365 天。定价页的个人档写批准、拒绝或从手机回答，并包含权限策略、MCP 和 API。

待核文档后半提到有的渠道作答是否记名。这次摘到的正文没有把每个渠道的记名差异列全，记名范围待核，不把「所有渠道都有实名」写成事实。

价格、开放与权限

官方自述三处页面一致写出团队价。5 人每月 59 美元，额外一人每月 12 美元，新工作区 3 天免费，试用期内取消不收费。

官方自述定价页另有个人档每月 9.99 美元、每月 5,000 条通知，以及 19.99 美元的不限通知档。合作方档写着每月 99、299、799 美元，按终端用户规模分。我们没有结账。

官方自述团队页写美国以外结账可能把同样的数字收成欧元或英镑。页面没有写人民币。国内发票和 App 上架待核。

真实使用信号

事实158 票来自情报站。官网没有公开付费团队数。

国内替代

待核飞书、钉钉、企微都有审批产品，但这次没有打开它们的文档，不能写它们是否能拦住 Cursor 或 Claude Code 的一次 git push。

假设若国内缺口存在，它在「编码工具的权限提问」而不在「请假审批」。这个缺口仍是假设。

可做的窄切口

建议只做两类拦截。git push，以及向外部发信。同意写进一张共享表，字段是谁、何时、哪条命令。

最小版与不做的范围

建议一个飞书或邮件机器人。先不覆盖所有 Agent。服务一个自己的五人小组两周。

不做不做 Mac 灵动岛客户端。不做全量 MCP 代理。不宣称和 Pushary 功能对等。

验证办法与建议的成功和停止条件

建议成功是两周内真实拦截至少 20 次，复盘时能指出责任人，并且没有一次误拦导致大家关掉它。

建议停止条件是小组改回在聊天里口头说「可以推」。

流量和付费

事实官网团队价是 59 美元 5 人。票数是 158。

建议可以用 20 秒演示讲清楚。收费要等那 20 次真实拦截出现。

风险

风险批准记录本身是敏感日志。漏记一次同意会在事故后无法追责。国内支付未核。若机器人能看到命令全文，密钥可能进日志。
