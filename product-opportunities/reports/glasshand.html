产品是什么

官方自述glasshand.com 写给 Agent 一台真的 iPhone 或 Mac，通过 API 接 Claude Code、Codex、Cursor 或其他 Agent。他们提供设备和操作。

事实情报站日榜把 Glasshand 放在编程分组的显示序 1，票数 293，并链到 Product Hunt。Product Hunt 页面本次 403，名次以情报站显示序为准。

给谁

官方自述定价页的用途是安装 App、登录自己的账号、用 eSIM 收验证短信，以及在 Mac 上用 Xcode 测应用。对象是需要苹果真机、而不是模拟器的 Agent 流程。

工作流程与场景

官方自述定价页写先租设备，再把一段提示贴进 Agent。Agent 看屏幕、点击和输入。我们没有走完这一步，所以看不到控制通道的权限模型。

官方自述释放设备时，页面写会擦除数据并重置。取消后设备保留到当前账期结束。这是页面句子，不是我们观察到的擦除结果。

价格、开放与权限

官方自述定价页 在 2026-11-06 写 iPhone 每月 60 美元，Mac 每月 90 美元，美元价另加税，按月，可取消。

待核有没有免费额度、企业合同和国内支付，定价页这次没写。不把第三方转载价再写一遍。

真实使用信号

事实能核对的是官网可打开，以及情报站上的 293 票。没有续租人数、设备在线率或退款率。

国内替代

事实扣子云设备费用 写云电脑和云手机按规格折成 CU，云电脑 12 积分每 CU 每天或 0.3 元每 CU 每天，云手机另有快速和经济模式。文档举例 2C4G 云电脑运行 1 天是 24 积分。这是虚拟规格，不是一台固定的苹果手机。

事实UBox 写用云真机 Skill 把 Android、iOS、HarmonyOS 真机接入 Agent，按使用时长结算，并记录画面和日志。页面没有给出和 60 美元对得上的单价。它是设备池，不是月租一台专用 iPhone。

事实Devicebase 写统一 API 操作手机、浏览器和电脑，注册送 500 积分，并称 10k+ 活跃开发者。活跃开发者是厂商首页句子，我们没有核对。它也没有写苹果真机独占月租。

可做的窄切口

建议只做安卓投屏教程或小范围代管，明确不提供苹果账号、短信和 iCloud。差异要写在第一屏，避免被理解成 Glasshand 的国内版。

最小版与不做的范围

建议一台自己的闲置安卓，投屏给一个本地 Agent，完成「打开设置并截图」这一条任务。记录失败在哪一步。

不做不采购 iPhone 库存。不帮用户养号。不承诺擦除达到厂商声称的程度。

验证办法与建议的成功和停止条件

建议成功是 5 个开发者愿意为这台安卓的一周代管支付一笔能覆盖流量和电费的钱，并且没有人要求登录别人的账号。

建议停止条件是需求立刻滑向批量账号或短信验证。

流量和付费

事实官网是月租美元价。情报站是 293 票。

建议录屏可以做内容。收款要先有单台设备的真实任务，再谈包月。

风险

风险登录用户自己的社交或支付账号有封号和隐私风险。eSIM 短信可能被用在验证滥用上。硬件损耗、海关和支付我们都没核。苹果对自动化的限制也不会因为换了出租方就消失。
