AI 使用深度水位：上手容易，用深很难

专题调研 · 2026-10-28（北京时间）· 情报站私有版 · 证据优先，无出处数字标「待核」

一句话结论：早期大家说「小白也能很快上手」指的是 L1 对话门槛；到了 2026 年，真正拉开差距的是 L3→L5——把模型嵌进工作流、交给 Agent、再做成可评测的流水线。触达率已经很高，深度分布却像漏斗。

本页把使用深度拆成 L0–L5，再按个人 / 企业通用办公 / 垂直（电商）对照；观点来自 X 与公开报告，YouTube/播客作补充。

深度漏斗 + 到达时间 越深越花时间

水位框架 L0→L5

L0

不用 / 几乎不用

听说过，或偶尔看别人演示；自己工作流里没有 AI。

L1

简单对话

当更好的搜索 / 润色器：问一句答一句，改邮件、翻译、写提纲。

L2

提示词 + 上下文喂料

多轮改写、贴文档/截图、定人设与格式；开始「会提问」。

L3

工具与工作流嵌入

IDE Copilot、自定义 GPT/Skill、表格分析、平台内置助手；AI 出现在固定步骤里。

L4

Agent 委托（半自动）

多步任务交给 Agent 跑，人审关键节点；开始改流程，而不只改单次回答。

L5

多 Agent 全自动流水线

编排、权限、评测、回放与生产接入；失败可追责、成功可规模化。

这是工作用的尺子，不是学术量表。同一人可以在写邮件上停在 L1，在写代码上到 L4。

为什么「简单」和「用深」不是一回事

Karpathy（2026-10-11）把认知差距画成漏斗：约 60 亿人几乎没接触大模型；约 10–20 亿人偶尔用免费聊天；约 2000 万人（他按 0.2% 估）在编程/数学里亲眼看到 Agent 几天做完原本几周的项目；约 5000 人能摸到内部更强系统。漏斗由「问题够不够大」「能力是否可验证（编程/数学）」「免费/付费/内部档位」三者叠出来。 原文 @karpathy · 中文转述 @dotey · 数字为作者 napkin math，非普查
OpenAI《Ending the Capability Overhang》（2026-01）：同一 ChatGPT Plus 档位里，典型 power user（约 95 分位）用的「thinking capabilities」是典型用户（中位数）的 7 倍；还指出许多企业用户从未点开数据分析 / 推理 / 搜索等高级能力。 OpenAI PDF
OpenAI Enterprise Signals（2026-05，原 B2B Signals）：前沿企业（用量约 95 分位）每名员工消耗的「intelligence」是典型企业的 3.5 倍（一年前约 2 倍）；消息量只解释差距的 36%，其余来自更深用法；Codex 上前沿企业人均消息约是典型企业的 16 倍。「典型企业用 AI 回答问题；前沿企业用 AI 执行复杂工作。」 openai.com
Microsoft 2026 Work Trend Index：在已使用 AI 的知识工作者里，Frontier Professionals 约占 16%——会用 Agent 做多步/多 Agent 工作流、常改流程、参与团队级规范；66% 的 AI 用户说 AI 让他们能把时间花在更高价值工作上，Frontier 群体里这一比例到 80%。组织因素对「感知到的 AI 影响」的解释力约是个人因素的两倍以上。 Microsoft WTI 2026 · 样本为「至少偶尔用 AI」的工作者，不是全体人口
Ethan Mollick 的 jagged frontier：模型在某些任务上很强、在另一些任务上离谱失败，而且边界会移动；他强调组织要用实验摸清边界，而不是当成又一个 IT 项目。相关视频/播客：Navigating the jagged frontier、Strange Loop · AI-first organization。 YouTube；时间轴因平台版本可能漂移，引用主题而非精确秒数
Andrew Ng 谈 agentic workflows：把「写草稿→检索→自检→改→测」做成循环，往往比单次提示更能榨出模型能力；常见模式含 reflection、tool use、planning、multi-agent。 What's next for AI agentic workflows ft. Andrew Ng
宝玉：搭 Agent 本身不值钱，「给 Agent 做工具、用 Agent 重构工作流」更值钱；并对「从没高频用过 Coding Agent 的人突然体验聪明模型+自动执行」的科幻感，对比天天用 Claude Code/Codex 的人「内心没什么波澜」。 搭 Agent · 刘姥姥进大观园

L1 偶尔问天气式问题、改简历、翻译。对应 Karpathy「1–2B 轻度免费用户」层。 用 Copilot/ChatGPT 写邮件、会议纪要摘要；无团队规范。 用大模型写一段详情文案、改标题；工具随手换。
L2 会贴长文/PDF、定格式、多轮打磨；开始存提示词。 按部门模板提问；上传制度/合同做比对（仍需人审）。 按品类 SOP 喂卖点、竞品截图；人改一版再发。
L3 Cursor/Copilot 写代码；自定义 GPT；连接网盘/日历。OpenAI：即便付费企业用户，仍有约 19%/14%/12% 从未用过数据分析/推理/搜索。 Office/IDE/CRM 内嵌助手成固定步骤；有共享提示词库。 平台生意管家、AI 客服、批量生图/切片。淘天白皮书：访谈商家中日常高频用约 60%+（深访偏重度用户，待核外推）。
L4 Claude Code/Codex/Computer Use 跑多步任务；人在关键点验收。MS：Frontier Professionals ≈ AI 用户的 16%。 Agent 处理工单/研报草稿；人审后再进生产系统。Anthropic Economic Index（2026-01）：Claude.ai 上 augmentation 约 52%、automation 约 45%（对话分类，非企业渗透率）。 巡店→策略→素材→客服半自动串联；人定预算与合规。淘天「AI 融合指数」：L3 深度应用约 24.77%，L4 全链路约 9.84%（白皮书口径）。
L5 个人「数字员工」常驻：定时任务、多 Agent、有日志与回滚。人口侧极稀；Karpathy 内部档 ~5000 人为量级参考（待核且不可直接等同）。 多 Agent + 权限/评测/Owned Intelligence；MS 称 M365 活跃 Agent 同比约 15×（大企业更高）。 「AI 店长 + 多个 AI 员工」托管经营环节；平台宣称覆盖多数场景，但全链路自洽仍少见。抖音智能文案助手活跃商家使用率公开案例 28.18%（单功能，非 L5）。

几组硬数据（只摘有出处的）

  • 触达 ≠ 深度：McKinsey State of AI —— 约 88% 受访组织在至少一项业务功能里「经常用 AI」；规模化仍远低于触达（2025 图表写 fully scaled 约 7%；2026 文称 scaling across enterprise 约 44%）。来源：2025 chart、2026 survey。
  • 员工比老板想的更敢用：McKinsey —— 13% 员工自称 gen AI 已占日常工作 >30%，C-suite 估计仅 4%。来源：Leaders underestimate…（2024 末美样本）。
  • Agent 在大企业更快：McKinsey 2026 —— 营收>$10 亿组织中，40% 称在 scale AI agents（上年 27%）；小组织约 22% 持平。
  • 电商水位已有自家尺子：淘天《2026 中国电商 AI 应用白皮书》L0–L4：L0 6.18%、L1 20.67%、L2 38.54%、L3 24.77%、L4 9.84%；淘系「已在用」约 70%。来源：白皮书 PDF / 中华网转述。平台白皮书可能偏积极，标待核外推。
  • 增强仍略多于全自动（消费端对话）：Anthropic Economic Index 2026-01 —— Claude.ai 上 augmentation 52% vs automation 45%。来源：Anthropic。

我的总结与洞察

  1. 真正的悬崖在 L2→L3，第二道在 L3→L4。学会聊天几乎零成本；把 AI 嵌进每天重复的步骤（L3）要改习惯和工具链；把结果权交给 Agent（L4）要评测、权限和「出了错谁负责」。OpenAI 的 7× / 3.5× / 16× 都在说：同一工具，深度差一个数量级。
  2. 「上手容易」没有过时，过时的是用它当终点。L1 仍然是大众入口；但若停在 L1，会像 Karpathy 说的那样：觉得模型「没啥用 / 这一年没进步」——因为你的问题规模根本压不到能力曲线。
  3. 可验证领域水位抬得最快。编程、数学、电商转化率、客服 SLA——有自动判分或业务指标，强化学习与产品投入都堆在这里；写长文、谈感受、跨部门政治协调抬升慢。jagged frontier 解释了为什么同一办公室有人「科幻片成真」，有人「就那样」。
  4. 垂直场景往往比通用办公更深，但深度被平台产品「承包」了。电商商家 L2–L3 比例高，很多是平台生意管家/客服组件，不等于商家自己会搭 Agent。对卖家来说，差异化更可能出在：私有数据、选品判断、内容品味，以及会不会把平台 AI 接到自己的 SOP。
  5. 对 Ocean 的含义：你已经长期在 L3–L4（Cursor/Codex、情报站自动化、CRM-Accio 垂直观察）。继续升水位不在「再多聊两句」，而在：① 把周报/监控/干净版发布做成可回放流水线（L5 的评测与失败处理）；② 电商侧用 Accio 类工具时盯「进工作流没有」而不是「会不会问」；③ 若做儿童 AI 教育或信息差教程，教的是 L2→L3 的跨越（喂料、验收、嵌入日常），不是又一个 ChatGPT 入门。
