小鱼向上游 · Skill 和 Prompt 区别是什么？

约 313 赞 · 389 收藏 · 8 评论；2 分 39 秒口播，定位是 AI PM 面试题。核心：区别不在长短，而在加载方式。Prompt 是每次塞进去的「这一次」的内容；Skill 是 Agent 按需加载的「这一类任务」的流程、标准和参考文档。举了代码审查的例子，最后讲坑：触发条件要写在描述里，用用户真会说的话写。

结构：常见误解 → 判断标准 → 各放什么 → 举例 → 踩坑 → 面试官口吻收尾。评论区几乎全是求逐字稿和总结。

看点：标题就是面试题原句；收藏高于点赞，大家当答案存。他可以写「我实际怎么用」，比背答案更有用。

Skill 和 Prompt 我是怎么分的：我每天真在用的那几个

AI 专题（独立一条线）

为什么今天能写：「Skill和Prompt区别是什么？」一天 311 赞、389 收藏，在「产品经理」「AI产品经理」两个词下都排前三；评论区全是求逐字稿。PRD 词下还有「产品经理必装的7个Skill」（32 赞）这类清单。大家在背面试答案，但没人讲「我每天按 skill 干活是什么样」。X 上卡兹克那篇一年搭 Agent 自动化系统的长文 1400+ 赞、2300+ 收藏，也说明「真实系统长什么样」有人要看。

接 11/02 日报里「PM skill 清单：真用过的才可信」那条预留；和课表方法主线不重复。

标题候选
  1. 「Skill和Prompt，我是这样分的」
  2. 「我每天让AI干活，靠的是这几份说明书」
  3. 「做产品的我，把常用流程写成了AI的说明书」
用什么素材
  • 他自己的规矩：每个机器人开始开发前先加载一份开发规则 skill，按对应流程走，写检查表（做了 / 跳过 / 不适用 + 原因）。这就是「这一类任务」的通用流程，正好对应热帖说的 Skill。
  • 「这一次」的内容才放 prompt：比如今天这篇要写什么、用哪批素材。可以用他派活时的一句话做对比图（隐去项目名）。
  • 热帖提到的坑他也踩过：触发条件要写在说明的第一行（描述），不然 AI 不知道什么时候该用。可以讲一次没写清导致 AI 没调用的真实经历（请他补，没有就不写）。
  • 可以截一张打码的 skill 列表当封面或第二张图，数量按发帖当天实际数。

不点名工具和平台，不讲成面试题标准答案，不写「效率提升 N 倍」。

可和 11/01 选题①「AI 功能的 PRD 多写哪几块」合成一篇，或作为它的下篇；接听记里讲评测和数据报告的几条（T11）。

标题候选
  1. 「AI功能demo跑通后，我还要补这几块」
  2. 「我做AI功能，最花时间的不是demo」
  3. 「AI产品上线前，我会先问这几个问题」
用什么素材
  • 他做大厂 PM 的一线经验：AI 功能上线前的评测、兜底、灰度怎么定（请他给 1-2 个脱敏例子，去掉公司名和内部数字）。
  • 听记 T11：AI 写数据报告时，哪些照原始结果写、哪些结论人来下，可以作「评测和归因」那块的例子。
  • X 素材一句带过：最新的通用 Agent 基准里，最好的模型也只完成一成左右任务（公开帖里不写来源）。

不写求职带教、不承诺「看完就能过面试」；数字只用公开基准，不放内部数据。

随口问一句，AI 把十几个文件全改了：我现在这样给它划边界

AI 专题 / vibe coding 系列

为什么今天能写：X 上 Axton 昨天说编程 agent「太负责」反而坏事：随口问一句逻辑怪不怪，它脑补需求把十几个文件全改了。小红书 AI 工具词下全是「AI 帮我做成一件事」（AI 做游戏 736 赞、全自动口播剪辑 333 赞），没人讲 AI 干过头怎么办。他有一套现成的规矩，是一手经验。

接 11/02 选题①「AI 当经理、AI 干活」，这篇讲具体的边界规矩，可以当它的下一篇或合并。

标题候选
  1. 「我问了AI一句话，它改了十几个文件」
  2. 「我给AI干活定了几条边界」
  3. 「AI太勤快，我反而要先管住它」
用什么素材
  • 他的规矩：每个项目先写计划和检查表；所有改动都走 PR，不直接推；做完按检查点逐条核；每个阶段结束写一份复盘放在项目里。
  • 「只问不改」要说清楚：提问时明确说「先别动代码，只回答」（如果他有这么用过；没有就换成他真实的说法）。
  • X 上另一条可作佐证：有人复现过，下载目录里放一个恶意说明文件就能让 agent 去装恶意包，说明 AI 读到什么就会照做（转述，待核，公开帖只说现象不写数字）。

不吓人、不写安全事故细节；不点名工具；只讲我定了哪几条、为什么。
