learn-in-public 账号：怎么涨、怎么变现

常见增长动作（有公开出处）

  • 过程目标先于粉丝 KPI：张咋啦自述起号只定「连续日更半年」，累计近 500 篇、小红书约 2万→18万（播客/虎嗅转载）→ 待核。出处：虎嗅文字版 · 小宇宙。
  • 公开学习倒逼理解：国内复盘文归纳 Zara 方法：高质量输入（长视频/builders）+ learn in public + learn by doing。出处：人人都是产品经理 · 实践张 Zara 方法。
  • B站「边做边讲」：花叔路径——先把 AI 拉进具体任务，再把试错拍成教程；开源项目反哺内容（盒饭财经/人人都是产品经理报道）。出处：我在B站和野生UP主学AI。
  • 小红书 build in public：创业者用笔记记录迭代与求助，产品更新本身即内容（Founder Park / 智源转述）。出处：智源社区转载。

常见变现路径（标清来源；自述待核）

  • 信任 → 人脉/机会（先不做广告）：Zara 路径偏长期分发；正职在身时更可持续（复盘文观点）。
  • 课程/会员库：范凯站方现读月/季/年会员（约 US$19.90 / 54.90 / 199.90），框架「AI 生产 + 个人 IP」。出处：fankaishuo.ai。
  • Newsletter 赞助/付费档：海外案例采访称 Superpower Daily 年收约 $10–15 万（赞助+beehiiv 广告网）；AI Tool Report 称约 $10 万/月量级——均为受访自述 → 待核。出处：Creator Spotlight · Superpower Daily · AI Tool Report。
  • 产品公开收入：levelsio / Marc Lou / Tony Dinh 等在 X bio 自报多产品月收——个人展示，非审计 → 待核；可学的是「做一件事就公开一件事」的节奏，不是数字本身。
  • 内容 → 产品：花叔等把教程与开源/App 互相导流（访谈叙述）。

对你：辅系列「我学 AI 的过程」先赚信任与素材；主线课表赚「把活干好」的专业标签；变现对齐远期产品课，不急广告。
