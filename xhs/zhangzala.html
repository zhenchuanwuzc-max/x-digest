爆款 vs 普通 · 差在哪

维度爆款侧普通侧（列表中位~1.5千赞）
可带走资产模板 / 开源 / 接入教程纯观点、活动预告
身份反差不会代码×GitHub 星无前后对比
标题如何/教程+演示/数字结果直播预告、松散随感
形式视频 demo + 极短文案图文预告互动低
收藏比常高于点赞（教程）接近或低于赞

语气 · 节奏 · 可套模板

  • 学生/Builder 语气：好奇、分享「我刚学会」，少爹味清单。
  • 正文极短；价值在 demo / 模板 / 开源。
  • 标题直说结果；禁用空洞「干货满满」「赋能」腔（与 Ocean 禁词对齐）。
  • 跨平台同一人设，不换人格。
【标题】我用 [工具] 做了 [可拿走的结果]（附模板/清单）
【封面】一句话结果 + 数字或前后对比
【正文 1–3 句】给什么 → 谁适用 → 一句反差
【资产】模板截图 / Prompt / 仓库 / 检查清单
【话题】3–5 个圈层标签
【别】30 分钟完整版口播（图文改一页清单）

给 Ocean（「AI具身牛马」）的借鉴

可抄动作

  1. 过程目标：辅系列定「连续发满 N 期」，代替粉丝 KPI。
  2. 每帖一件能拿走的东西：待办 Prompt / 金句分类表 / 代理检查清单。
  3. 成长反差图文：「大厂 PM 不会手写代码，用 AI 做了三个小工具」。
  4. 评论定选题：高频问题变下一篇标题。
  5. 爆了再发降级版：同主题「0 基础 / 一页版」（学 Frontend slides 连更）。

暂时别学

  • 真·日更半年近 500 篇（全职/近全职产能）；你用周更主线+辅系列。
  • 哈佛·GGV·字节 PMM 标签冷启动；你用「大厂 PM 现场」即可。
  • 真人出镜口播长视频 / Demo Day 湾区节奏；生产线先图文卡。
  • 主线做成纯 vibe coding 工具号——方法密度仍要对齐 Lenny。
