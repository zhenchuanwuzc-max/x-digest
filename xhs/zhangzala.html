4. 主题分布与选题规律

  • 什么最容易爆：工具 / 教程 + 可复用模板（HTML Slides 4.3 万赞 / 6.2 万藏）；可落地方法 + demo（Claude Code 接飞书 1.5 万赞）。
  • 成长反差：「不会写代码却有 3 万 GitHub 星」类叙事，小红书与 X 都靠前。
  • 标题写法：平铺直叙说清给你什么——「如何…」「教程+演示」「完整版」「太爽了」。数字结果（3 万星、涨粉 7 万）当钩子。
  • 形式：主页前 60 篇绝大多数是视频（V）；图文（I）多为预告/活动。封面常真人出镜 + 大字条，或白底大字卡。
  • 正文极短：1–3 句 + 话题标签；价值在视频/模板里，不在长文。
  • 量级：列表页点赞中位数约 1.5 千（采集观察）；真正爆的集中在模板、开源接入、成长对比。
  • 话题圈：AI-native 工作方式、怎么学 AI、做内容的方法、taste、vibe coding、agent。

咱们发的是图文，视频那套没法照搬；能借的是选题钩子、标题直说、以及「每篇附一个能拿走的东西」。

5. 给 Ocean 的借鉴

语气按你号的规矩：第一人称、平实、不说教。下面只当选题备忘，不是 checklist。

项目帖怎么写（待办 / 金句 / 网络代理）

别停在「我做了个啥」。她爆款的共性是读者能直接拿走模板或步骤。三篇可以各自挂一件东西：

  • 待办：讲你怎么用 AI 把待办拆成可执行项；附一页提示词模板或 skill 片段（复制就能用）。
  • 金句：讲收集 / 回看 / 引用的闭环；附分类表或导出格式，别人能套到自己的笔记库。
  • 网络代理：讲你踩过的配置坑和最终工作流；附一份脱敏配置清单或检查步骤（不写密钥、不写公司内网细节）。

标题可以学她的直给：「我用 AI 做了个待办助手（附模板）」「PM 的金句库怎么搭」「网络代理我是这么配的（检查清单）」——陈述句，不喊口号。

再写一篇成长对比

对标她「不会写代码也有 GitHub 星」那条。你的版本可以是：我是大厂产品经理，不会手写代码，用 AI 做了几个小工具——待办、金句、网络代理当证据摆上去。重点写前后对比和现在每天怎么用，少写鸡汤。

形式上咱们继续图文：封面一句话结果 + 内页步骤/模板；正文三短段 + 话题。视频不是必须。

从她那儿少借什么

  • 真人出镜口播长视频——你现在的生产线是图文卡，硬切成本高。
  • 「完整版 30 分钟」这类时长钩子——图文改成「一页清单 / 七张卡」更合适。
  • 湾区线下 / Demo Day 节奏——你有大厂现场，用脱敏项目故事替代即可（比如跨部门履约项目讲 GAIN）。
