# 小红书全入口布局

Ocean 要主栏在导航旁边的空白里居中，并把左侧二十多项收成少数分组。宽屏不要贴着导航，也不要铺满。这次只动壳层。正文、选题数据和自动化都没改。

## 原因

全入口和日页的后写规则是 `.shell { max-width: none }`，主栏是 `.main { max-width: 78rem }`，没有 `justify-self: center`。导航宽 14rem（224px）。主栏作为网格项会向左拉伸，最多 78rem（1248px）。

改之前在本机 Chrome 里量到：

| 页面 | 视口 | 主栏左空隙 | 主栏右空隙 | 主栏宽 | 中心偏移 |
| --- | --- | --- | --- | --- | --- |
| 全入口、日页目录、2026-11-05 | 1440 | 0 | 0 | 1216 | 0 |
| 同上 | 1920 | 0 | 448 | 1248 | -224 |
| 同上 | 390 | 0 | 0 | 390 | 0，页面无横溢 |

1920 的主栏贴着导航，右边空 448px。1440 的主栏铺满导航右侧。

## 现在的壳

`xhs/xhs-shell.css` 在 `</head>` 最后加载，盖过页内旧规则。主栏宽是 `min(68rem, calc(100% - 3rem))`，在导航右侧的列里居中。68rem 等于三张选题卡的下限：每张 `minmax(22rem, 1fr)`，两道 1rem 缝。再窄就会从三列掉成两列。1440 扣掉导航后还剩 1216px，68rem 是 1088px，左右各 64px。

全入口左侧用四个 `<details>`。今天和选题默认展开。素材与对标、库与计划默认收起。成长记录和往期日页留在分组外面，成长记录仍是 `growth/` 独立页。全入口正文还在这一页，没有改成跳转。

手机宽度小于 900px 时，只有带分组的全入口把侧栏改成页顶折叠。日页仍用原来的横滑链接，避免同一条样式把日页导航也展开成一长列。

全入口 1440 的选题区仍是三列（352px × 3）。侧栏四个分组都能打开，打开后 23 个原链接都可见。页内锚点都能找到对应 `id`。`#picks` 能滚到「汇总建议选题」。`curriculum.html`、`growth/`、`day/` 返回 200。成长记录链接不在 `<details>` 里面。

## 重生成

页脚写这些 HTML 由 `xhs_library.py` 和 `xhs_day_build.py` 生成。这两个文件不在本仓库，这台机器上也没有。GitHub 代码搜索没有定位到它们。所以生成器源码这次没改，下一次外部生成会不会盖掉链接，没有验证。

本仓库里的补法是跑：

```
python3 xhs/apply_xhs_shell.py
```

脚本把样式链接放回 `</head>` 末尾。全入口如果还是旧的平铺导航，会换成分组。再跑一次输出 `unchanged`。`python3 xhs/test_xhs_shell.py` 会拿 `main` 上的旧全入口再盖一次，确认结果稳定，并且正文还在。
